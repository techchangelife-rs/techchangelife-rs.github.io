算法基础：深度优先 (DFS) 与 广度优先 (BFS) 精讲 ​

第一篇：搜索的艺术 —— DFS 与 BFS 概览 ​

在计算机科学中，当我们需要遍历或搜索树（Tree）或图（Graph）结构时，最核心的两种策略就是深度优先搜索 (Depth-First Search) 和 广度优先搜索 (Breadth-First Search)。

1.1 直观对比：找钥匙的两种方式 ​

想象你在一个拥有很多房间的豪宅里找一把丢失的钥匙：

  • 深度优先 (DFS)：你选择一个走廊，一直走到尽头，推开每一扇门。如果没找到，就退回到上一个分叉口，换另一条路继续走到底。这是一种“不撞南墙不回头”的策略。
  • 广度优先 (BFS)：你先检查当前大厅的所有门，如果没有找到，再进入这些门后的所有房间。这是一种“地毯式搜索”的策略。

1.2 核心差异 ​

特性深度优先 (DFS)广度优先 (BFS)
核心数据结构栈 (Stack) (或递归调用栈)队列 (Queue)
搜索方式一条路走到底，再回溯逐层向外扩散
空间复杂度与深度成正比 O(h)O(h)O(h)与宽度成正比 O(w)O(w)O(w)
适用场景寻找所有解、路径探索、拓扑排序寻找最短路径、层级遍历

第二篇：深度优先搜索 (DFS) —— 探险者的足迹 ​

2.1 递归实现：代码的优雅 ​

递归是 DFS 最自然的表达方式，因为计算机的函数调用栈本身就是一个“栈”。每次递归调用都相当于将一个节点压入栈中，函数返回则相当于出栈。

typescript
/**
 * 递归版 DFS
 * @param node 当前节点
 * @param visited 已访问节点的集合
 */
function dfsRecursive(node: Node | null, visited: Set<Node>) {
  // 1. 终止条件：节点为空或已访问过
  if (!node || visited.has(node)) return;
  
  // 2. 处理当前节点
  console.log("访问节点:", node.value);
  visited.add(node);
  
  // 3. 递归遍历邻居
  for (const neighbor of node.neighbors) {
    dfsRecursive(neighbor, visited);
  }
}

2.2 迭代实现：显式栈 ​

为了防止深度过大导致栈溢出（Stack Overflow），我们可以使用显式的栈来模拟递归过程。这在处理超大规模数据时更为稳健。

typescript
/**
 * 迭代版 DFS
 * @param startNode 起始节点
 */
function dfsIterative(startNode: Node) {
  const stack = [startNode];
  const visited = new Set<Node>();
  
  while (stack.length > 0) {
    const node = stack.pop()!; // 出栈
    
    if (visited.has(node)) continue;
    
    // 处理当前节点
    console.log("访问节点:", node.value);
    visited.add(node);
    
    // 将邻居压入栈中
    // 注意：为了保持与递归相同的访问顺序（左优先），邻居通常逆序入栈
    for (let i = node.neighbors.length - 1; i >= 0; i--) {
      const neighbor = node.neighbors[i];
      if (!visited.has(neighbor)) {
        stack.push(neighbor);
      }
    }
  }
}

2.3 深度追踪：执行过程模拟 ​

假设我们有如下结构的树：

    A
   / \
  B   C
 / \   \
D   E   F

DFS 访问顺序：A -> B -> D -> E -> C -> F。

  1. 从 A 开始，压入 A。
  2. 弹出 A，压入 C, B。
  3. 弹出 B，压入 E, D。
  4. 弹出 D，没有邻居。
  5. 弹出 E，没有邻居。
  6. 弹出 C，压入 F。
  7. 弹出 F，完成。

2.4 关键应用：回溯算法 (Backtracking) ​

DFS 是回溯算法的灵魂。在解决“八皇后”、“数独”或“全排列”问题时，我们本质上是在一棵巨大的状态空间树上进行 DFS。当发现当前路径无法达成目标时，DFS 的“回溯”特性允许我们撤销上一步的选择，尝试其他可能性。

第三篇：广度优先搜索 (BFS) —— 扩散的波纹 ​

3.1 核心机制：队列 ​

BFS 严格按照“先见到的先访问”原则，因此必须使用先进先出（FIFO）的队列。它就像在水中投入一颗石子，波纹一圈一圈均匀地向外扩散。

typescript
/**
 * 广度优先搜索 BFS
 * @param startNode 起始节点
 */
function bfs(startNode: Node) {
  const queue = [startNode]; // 使用数组模拟队列
  const visited = new Set<Node>();
  
  // 入队即标记已访问
  visited.add(startNode);
  
  while (queue.length > 0) {
    const node = queue.shift()!; // 出队 (O(n) in array, O(1) in linked list)
    
    // 处理当前节点
    console.log("访问节点:", node.value);
    
    // 将所有未访问的邻居加入队列
    for (const neighbor of node.neighbors) {
      if (!visited.has(neighbor)) {
        visited.add(neighbor); // 标记已访问
        queue.push(neighbor);  // 入队
      }
    }
  }
}

3.2 广度追踪：层级遍历过程 ​

同样使用之前的树结构：

    A
   / \
  B   C
 / \   \
D   E   F
1
2
3
4
5

BFS 访问顺序：A -> B -> C -> D -> E -> F。

  1. 第一层：访问 A，将邻居 B, C 加入队列。
  2. 第二层：
    • 访问 B，将邻居 D, E 加入队列。
    • 访问 C，将邻居 F 加入队列。
  3. 第三层：访问 D, E, F。

3.3 关键优势：无权图的最短路径 ​

在无权图（即所有边的权重都相等）中，BFS 具有一个极其重要的特性：它第一次搜索到目标节点时，所经过的路径一定是步数最少的路径。

  • 应用场景：迷宫的最短出口、社交网络中的二度关系、路由协议中的跳数计算。

第四篇：多语言实现大荟萃 ​

4.1 Python：利用 collections.deque 优化 BFS ​

Python 的 list.pop(0) 是 O(n)O(n)O(n) 操作，因此在实现 BFS 时，推荐使用 collections.deque 以获得 O(1)O(1)O(1) 的出队性能。

python
from collections import deque

def bfs_python(start_node):
    queue = deque([start_node])
    visited = {start_node}
    
    while queue:
        node = queue.popleft() # O(1)
        print(f"访问节点: {node.value}")
        
        for neighbor in node.neighbors:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

4.2 Java：使用 Queue 接口 ​

Java 提供了丰富的集合框架，BFS 通常结合 LinkedList 或 ArrayDeque 实现。

java
import java.util.*;

public void bfsJava(Node startNode) {
    Queue<Node> queue = new LinkedList<>();
    Set<Node> visited = new HashSet<>();
    
    queue.add(startNode);
    visited.add(startNode);
    
    while (!queue.isEmpty()) {
        Node node = queue.poll();
        System.out.println("访问节点: " + node.value);
        
        for (Node neighbor : node.neighbors) {
            if (!visited.contains(neighbor)) {
                visited.add(neighbor);
                queue.add(neighbor);
            }
        }
    }
}

第五篇：实战演练 —— 迷宫、社交网络与拓扑 ​

5.1 迷宫求解：路径 vs 最短路 ​

  • DFS：适合判断“迷宫是否有解”。它会沿着一条路走到底，直到碰壁才回头。这种策略在迷宫分支很多时，可能会在无效路径上耗费大量时间，但它的内存占用（仅需记录当前路径）通常比 BFS 小。
  • BFS：适合寻找“迷宫的最短路径”。因为它按层级扩展，所以当它到达终点时，所走的路径必然是最短的。代价是需要存储当前层级及其所有邻居，内存消耗随距离呈指数级增长。

5.2 社交网络中的“六度分割” ​

在分析社交网络中两个人的关系距离时，通常使用 BFS：

  1. 第一层：你的直接好友（一度）。
  2. 第二层：好友的好友（二度）。
  3. 通过 BFS，我们可以快速得出两个人之间需要经过多少个“中间人”。

5.3 任务调度与拓扑排序 ​

DFS 的回溯特性使其非常适合处理依赖关系。

  • 拓扑排序 (Topological Sort)：通过 DFS 遍历有向无环图 (DAG)，在退出递归（回溯）时将节点压入结果栈，最后逆序输出。这常用于解决软件编译依赖、课程学习先后顺序等问题。

第六篇：高级优化与变体 ​

6.1 剪枝优化 (Pruning) ​

在 DFS 搜索过程中，如果我们能够提前判断出当前分支不可能产生最优解（或者已经超出了已知最优解的步数），就立即停止该分支的搜索。

  • 应用：Alpha-Beta 剪枝（在象棋、围棋 AI 中极大减少了博弈树的搜索量）。

6.2 迭代加深搜索 (IDDFS) ​

这是一个融合了 DFS 和 BFS 优点的天才想法。

  1. 限制 DFS 的最大搜索深度 ddd。
  2. 如果没有找到目标，则增加深度 d+1d+1d+1 重新开始搜索。
  • 优点：它像 BFS 一样能找到最短路，但内存占用仅为 O(d)O(d)O(d)，解决了 BFS 的内存溢出问题。

6.3 双向 BFS (Bidirectional BFS) ​

如果已知搜索的起点和终点，可以同时从两头开启 BFS。

  • 原理：当两个方向的搜索范围相遇时，路径即被找到。
  • 效率：将搜索空间从 O(bd)O(b^d)O(b​d​​) 压缩到了 O(2⋅bd/2)O(2 \cdot b^{d/2})O(2⋅b​d/2​​)，在大型社交网络或字谜游戏中极其高效。

第七篇：你知道吗？ —— 趣味冷知识与避坑指南 ​

  1. “广东优先”搜索？ 这其实是一个程序员圈子里著名的“输入法惨案”。由于“广度 (Guangdu)”与“广东 (Guangdong)”拼音接近，许多开发者在讨论算法时会不小心打出“广东优先搜索”。久而久之，这成了一个幽默的冷梗。虽然广东的美食确实很“优先”，但在代码里，我们还是得老老实实写“广度优先”。
  2. 迷宫的起源：古希腊神话中的米诺陶诺斯迷宫，英雄忒修斯使用的“线团”策略，本质上就是一种物理化的 DFS 回溯。他用线记录路径，遇到死胡同就沿线退回。
  3. 内存杀手：在大型图搜索中，BFS 可能会因为存储了数百万个待访问节点而导致 OOM (Out Of Memory)。这也是为什么在极深搜索（如寻找宇宙中两个星系的连接路径）中，人们更倾向于使用迭代加深的 DFS。
  4. 面试避坑指南：
    • 忘记标记 Visited：这是新手最容易犯的错误，会导致在图中陷入死循环。
    • BFS 误用数组 pop(0)：在 Python 等语言中，这会使复杂度从 O(1)O(1)O(1) 退化为 O(n)O(n)O(n)。
    • DFS 递归过深：在处理上万层的树结构时，务必考虑改用迭代法。

第八篇：实战演练 —— 迷宫寻路 (TypeScript) ​

以下是一个结合了 DFS 回溯思想的迷宫寻路函数示例：

typescript
type Point = [number, number];

function findPath(maze: number[][], start: Point, end: Point): Point[] | null {
  const rows = maze.length;
  const cols = maze[0].length;
  const path: Point[] = [];
  const visited = new Set<string>();

  function dfs(r: number, c: number): boolean {
    // 边界检查与障碍检查
    if (r < 0 || r >= rows || c < 0 || c >= cols || maze[r][c] === 1 || visited.has(`${r},${c}`)) {
      return false;
    }

    path.push([r, c]);
    visited.add(`${r},${c}`);

    // 到达终点
    if (r === end[0] && c === end[1]) return true;

    // 探索四个方向：上下左右
    const directions = [[0, 1], [1, 0], [0, -1], [-1, 0]];
    for (const [dr, dc] of directions) {
      if (dfs(r + dr, c + dc)) return true;
    }

    // 回溯：当前路径不通，从路径中移除
    path.pop();
    return false;
  }

  return dfs(start[0], start[1]) ? path : null;
}

第十篇：实战练习与深度解析 ​

【基础关】 ​

  1. 题目：在遍历一棵高度为 HHH 的平衡二叉树时，DFS 和 BFS 哪个更省内存？ 解答：DFS 更省内存。DFS 的空间复杂度为 O(H)O(H)O(H)（调用栈深度），而 BFS 的空间复杂度取决于树的最大宽度，在平衡二叉树中宽度约为 2H−12^{H-1}2​H−1​​。

【进阶关】 ​

  1. 题目：如何判断一个有向图中是否存在环？ 解答：可以使用 DFS。在遍历过程中，如果访问到了一个“正在访问中”（处于递归栈中）的节点，则说明存在环。

【奥数/算法关】 ​

  1. 题目：在棋盘上，一个马（Knight）从 (0,0)(0,0)(0,0) 移动到 (x,y)(x,y)(x,y) 最少需要多少步？ 解答：这是一个典型的最短路径问题，应该使用 BFS。每一层代表马跳跃的一步，第一次到达目标坐标时的层数即为最小步数。

结语：在逻辑的分叉口选择 ​

DFS 和 BFS 是算法世界的两盏明灯。DFS 像是一个孤独的探险者，追求极致的深度，在迷雾中通过不断的尝试与回溯寻找出口；而 BFS 像是一个缜密的侦探，追求全面的覆盖，通过层层推进确保不错过任何一个细节。

掌握了这对“双子星”算法，你不仅能解决复杂的图论难题，更能培养出一种系统化的思维方式 —— 在面对未知的选择时，是该孤注一掷地深挖，还是稳扎稳打地平铺？
