小学生也能懂的AI魔法！王者荣耀AI导师是怎样炼成的？（六）——开启上帝视角：实时意识指导 ​

亲爱的峡谷召唤师们，还有在屏幕前陪着孩子一起学魔法的家长们，大家好！

在前面的几节课里，我们给 AI 导师发了《王者图鉴》，它学会了查字典；我们又给它发了算盘，它学会了算经济差、看阵容。现在的 AI，在游戏开局之前，绝对是一个能说会道的“纸上谈兵”大师。

但是，打王者荣耀，光在泉水里讲道理是没用的！ 低段位的玩家喜欢拼手速、拼谁的连招按得快；而真正的高手、百星王者，拼的是什么？ 拼的是**“意识”**！

什么是意识？

  • 就是游戏刚刚进行到 1分30秒 的时候，你正在下路（发育路）开心地打着小兵，突然感觉后背发凉，你知道对面的打野兰陵王大概率已经刷完了野怪，升到了4级，正隐着身准备来抓你了！于是你果断放弃小兵，闪现躲回塔下。
  • 就是游戏进行到 9分50秒 的时候，你知道马上就要刷新决定胜负的“暗影主宰”了。如果你是辅助，你会提前跑到龙坑旁边的草丛里蹲好，就像个尽职的保安一样，给队友点亮视野。

这就叫意识！这就是为什么别人能上王者，而你总是被抓成提款机的原因。

今天，我们要挑战整个系列里最酷、最像黑客帝国的一个技能：situation_awareness（实时局势雷达）。 我们要给原本“又瞎又聋”的 AI 导师，戴上一块精准的智能手表，再给它塞一张峡谷的活地图！ 让它开启传说中的**“上帝视角”**，随时在你的耳边大吼：“别压线了！赶紧跑！”

准备好了吗？我们将进入魔法的深水区！

第一章：给 AI 戴上智能手表——什么是“时间线意识”？ ​

大语言模型（LLM）平时是个完全没有时间观念的家伙。如果你不告诉它，它根本不知道现在是公元几年，更不知道你这局游戏打了多久。

为了让 AI 拥有“意识”，我们必须把王者荣耀里那套极其严密的时间线节奏，像刻光盘一样，死死地刻在代码里。

（图：把王者荣耀的节奏点硬编码进代码里，告诉AI什么时间该干什么事，这就是“上帝视角”的秘密！）

1.1 设计说明书（Zod 保安再次上线） ​

我们要写第三个大招了。打开我们熟悉的 src/tools/awareness.ts，先把 Zod 保安请出来，定下规矩。 为了让 AI 能开启“上帝视角”，我们必须强制要求 AI 每次调用这个技能时，都要向代码汇报两件极其重要的事情：

  1. 现在几分钟了？
  2. 你（玩家）在地图的哪个位置？
typescript
// src/tools/awareness.ts
import { z } from "zod";
import { zodToJsonSchema } from "zod-to-json-schema";

// 告诉 AI：想问我要战术？先把时间地点报上来！
export const AwarenessSchema = z.object({
  gameTimeMinutes: z.number()
    .min(0, "游戏还没开始呢！")
    .max(60, "打了一个小时？手机都冒烟了吧！")
    .describe("现在游戏进行到第几分钟了？注意，支持小数！比如 1.5 代表 1分30秒。"),
  
  myLane: z.enum(["对抗路", "中路", "发育路", "打野", "游走"])
    .describe("玩家当前在地图的哪条路上混？"),
});

// 包装成 MCP 认识的“雷达说明书”
export const awarenessToolDef = {
  name: "situation_awareness",
  description: "【上帝视角雷达】根据当前精确的游戏时间和玩家所在分路，提供最致命的防抓（防Gank）警告、控龙建议和推塔节奏。保命必备！",
  inputSchema: zodToJsonSchema(AwarenessSchema),
};

1.2 核心雷达逻辑：把峡谷的秘密写进代码 ​

有了时间，代码就能像先知一样预测未来了！我们要把王者荣耀里最容易送命的几个时间点写死在逻辑里。

typescript
// 继续在 src/tools/awareness.ts 里写
export async function executeAwareness(args: any) {
  // 1. 保安搜身，确保传进来的时间是数字
  const { gameTimeMinutes, myLane } = AwarenessSchema.parse(args);
  
  // 准备一个大喇叭，用来装我们要发出的警告
  let warnings: string[] = [];
  let macroStrategy = ""; // 宏观战术

  // ================= 致命节点 1：打野出山 (1分30秒 ~ 2分钟) =================
  // 为什么是这个时间？因为正常打野刷完一圈野怪升到 4 级，差不多刚好是这个时候！
  if (gameTimeMinutes >= 1.5 && gameTimeMinutes <= 2.0) {
    warnings.push("🚨 红色警报！滴滴滴！敌方打野大概率已经到达 4 级，并且正在草丛里盯着你！");
    
    // 如果玩家是个脆皮射手或者正在上路火拼
    if (myLane === "对抗路" || myLane === "发育路") {
      warnings.push(`你个玩【${myLane}】的，千万别贪那一个小兵了！现在立刻、马上给我滚回防御塔底下！连河道都不要去！`);
    } else if (myLane === "中路") {
      warnings.push("中路小心！别去支援边路了，河道草丛里可能有五个壮汉在等你！");
    }
  }

  // ================= 关键节点 2：双龙汇聚 (9分50秒 ~ 10分30秒) =================
  // 10分钟，暗影主宰和暗影暴君同时刷新，这是拉开经济差的最关键时刻！
  if (gameTimeMinutes >= 9.8 && gameTimeMinutes <= 10.5) {
    macroStrategy = "🐉 关键时刻到了！10分钟的双龙马上刷新！这是决定胜负的时刻！";
    
    if (myLane === "游走") {
      warnings.push("辅助大哥，别跟着射手在下路梦游了！赶紧去龙坑旁边的草丛里蹲好，占领视野！别让对面偷偷把龙打了！");
    } else if (myLane === "打野") {
      warnings.push("打野快看地图！对面打野如果在下路露头，你立马去开上路的龙，不要犹豫！");
    } else {
      warnings.push("所有人注意，别自己去带线了，随时准备向龙坑集合打团战！");
    }
  }

  // ================= 终极节点 3：风暴龙王 (20分钟以后) =================
  if (gameTimeMinutes >= 20.0) {
    macroStrategy = "⚡ 决战时刻！风暴龙王已经降临！";
    warnings.push("游戏进行到这个地步，死一次可能就要被一波推平水晶了。所有人必须抱团，五个人绑在一起走！谁敢单带被抓，谁就是千古罪人！");
  }

  // 总结汇报
  return {
    currentTime: `当前游戏时间：${gameTimeMinutes} 分钟`,
    currentLane: `玩家位置：${myLane}`,
    coach_voice: warnings.length > 0 ? warnings.join("\n") : "现在是很安全的和平发育期，赶紧努力刷钱，别发呆！",
    macro_strategy: macroStrategy
  };
}

第二章：注入灵魂——戴上戏剧面具的 MCP Prompts ​

刚才我们写出来的警告词，虽然很实用，但是听起来有点像没有感情的播音员。 如果只是机械地念字，那就不是“导师”，那顶多是个语音播报器。

想象一下你在打游戏，突然犯了个低级错误。你是希望一个冷冰冰的机器音对你说：“对不起，您的操作有误。”，还是希望一个脾气暴躁、恨铁不成钢、但又极其专业的老教练在耳边吼你：“你在干什么？！不想赢就点投降，别在这梦游！”

显然是后者！因为人设（Persona） 能够极大地改变用户的体验，让你觉得你是在和一个活生生的人交流！

在 AI 魔法世界里，怎么给 AI 换性格呢？这就需要用到一项被称作**“提示词工程（Prompt Engineering）”**的顶级黑魔法。

2.1 什么是提示词工程（Prompt Engineering）？ ​

我们再来打个生动的比方。 AI 就像是一个演技爆表、拿过奥斯卡影帝的超级演员。但是，这个演员在没上台之前，是一张白纸。 如果你直接推他上台，不给他剧本，他就会像个机器人一样，用最官方、最无聊的话跟你聊天（比如 ChatGPT 最爱说的“作为人工智能语言模型，我建议你……”）。

提示词工程，就是你作为导演，给这个演员写剧本、定人设、发服装的过程！

你给他戴上小丑的红鼻子，他就会用滑稽的声音讲笑话； 你给他穿上白大褂，他就会用专业的医学术语分析你的病情； 你给他戴上耳麦、穿上西装，他就会变成 KPL（王者荣耀职业联赛）的冠军教练！

2.2 为什么 MCP 要专门搞一个 Prompts 模块？ ​

在以前，我们要给 AI 定人设，必须每次聊天的时候，都在对话框里手打几百字：“你现在是一个教练，你脾气很暴躁，你懂王者荣耀……” 烦都烦死了。

MCP（万能插头协议）太聪明了！它专门设计了一个 Prompts（提示词）模块。 这就相当于在我们的服务站（MCP Server）里，准备了一个**“戏剧面具挂墙”**。 我们把写好的、几千字的极品人设剧本，做成一个面具挂在墙上。当 AI 连上我们的服务站时，它只需要大喊一声：“给我戴上【教练面具】！” 瞬间，它的灵魂就被替换了！

（图：通过MCP给AI戴上KPL冠军教练的面具，语气立刻变得犀利、毒舌、一针见血，这才是真正的伴游导师！）

3.2 编写极其硬核的 Prompt 剧本 ​

当 AI 看到目录，兴奋地喊出 GetPromptRequestSchema，要求戴上 hok_coach_persona 这个面具时，我们就把写好的神级剧本发给它。

前方高能！请仔细阅读这段 Prompt，这是 Prompt Engineering 的典范写法！

typescript
// ================= 当 AI 请求戴上面具时，下发剧本 =================
server.setRequestHandler(GetPromptRequestSchema, async (request) => {
  if (request.params.name === "hok_coach_persona") {
    return {
      description: "王者荣耀暴躁教练人设",
      messages: [
        {
          role: "user",
          content: {
            type: "text",
            // 下面这段长文本，就是注入灵魂的“提示词工程”！
            text: `你现在不再是一个人工智能助手，而是一名刚带队拿过 KPL 总冠军的顶级电竞教练！
你的名字叫“羽教”。
你正在一对一指导一个极其容易犯错、没有意识的新手玩家打《王者荣耀》。

【你的性格与语气】：
1. 极其专业：满嘴都是电竞术语（如：卡视野、控兵线、Gank、拉扯、掉点）。
2. 脾气暴躁、恨铁不成钢：当玩家在错误的时间出现在错误的地方时，你会用犀利、毒舌的语言直接骂醒他，绝不留情！
3. 护短：虽然你骂他，但你非常渴望他能赢。你的建议总是最致命、最能保命的。

【你的行为准则】：
当用户告诉你他当前的游戏时间和位置时，你必须立刻、毫不犹豫地调用 \`situation_awareness\` 工具！
拿到工具返回的数据后，你要用你那暴躁教练的语气，把工具里的警告（warnings）翻译出来，大声吼给玩家听！

【对话示例】：
玩家：教练，现在1分40秒，我在发育路压着对面的塔打！
你（大吼）：你是不是疯了？！1分40秒你压什么塔？！对面打野红开现在绝对已经4级了，正蹲在你旁边的草丛里准备拿你的一血！连个炮车都贪，你是提款机吗？立刻给我闪现滚回防御塔底下！掉个兵总比掉人头强，听懂了没有？！`
          }
        }
      ]
    };
  }
  throw new Error(`找不到名为 ${request.params.name} 的面具！`);
});

第五章：总结与高能预警 ​
